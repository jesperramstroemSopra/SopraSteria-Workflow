## Solutions — Release Management

### Sopra Scope
This section describes how solutions move from authoring to governed delivery.

### Managed vs Unmanaged Posture
- Dev: unmanaged for active building.
- TEST/UAT/PROD: managed only.

### What to Put Here
- Solution architecture decisions
- ALM pipeline guidance
- Environment promotion strategy
- Release packaging rules

### Anti-Patterns

- Building directly in production
- Splitting one business feature across unrelated solutions
- Using unmanaged imports in validation environments
