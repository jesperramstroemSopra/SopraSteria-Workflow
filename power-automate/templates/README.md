## Flow Templates

Use these template conventions for Sopra-standard flow starters.

### Template Goals
- Keep flows small and composable.
- Standardize naming, error handling, and logging.
- Make the first action obvious from the template name.

### Example Template Names
- `spr_SyncDataverseToTeams`
- `spr_HandleApprovalRequest`
- `spr_NotifyOnCaseUpdate`

### Anti-Patterns

- Generic "blank flow" templates with no standards
- Copying a production flow just to start a new one
- Templates that omit error handling or logging by default
