## Naming Conventions

### Sopra Prefixes
- `spr_` for shared solution assets
- `spr`-prefixed environment variables where naming must be machine-friendly
- PascalCase for display names and logical business artifacts

### Examples
- `spr_LeaveRequest`
- `spr_EmployeeDirectory`
- `CheckLeaveBalance`
- `spr_dataverseBaseUrl`

### Anti-Patterns

- Mixed casing in the same solution
- Project-specific abbreviations nobody else recognizes
- Names that encode environment instead of role
